## Invariants

- Drafts survive Settings-tab navigation and are discarded when Settings closes.
- Source discovery never commits settings, admits a scope, or imports images.
- Application reserves synchronization before publishing the reviewed integration fields.
- Cursors and snapshots belong to the target database/owner, not the editable draft.
- Before gallery commitment, cancelled or failed replacements restore the preceding configuration and verified view. Retry retains the submitted target and reviewed options, resolving that scope's checkpoint again rather than retrying the restored owner. A first connection retains the submitted configuration behind recovery if preparation fails or is cancelled.
- After commitment, cancellation or ordinary sync failure retains the selected configuration and completed writes, refreshes partial results, and offers Retry using applied options. Ownership uncertainty gates the view again.
- Cancellation covers preparation, image batches, caches, and orphan recovery. Already-running native work settles before the reservation is released. Cancelled work drops queued automatic reruns; later Live Watch events and restart catch-up remain enabled.
- View readiness is separate from operation progress. Newly committed image batches refresh queries at most once per second; the gallery retains its existing virtualized rendering and browsing state.
- Reuse an admitted current-owner view only with compatible preparation evidence and an unchanged source snapshot. Board-option changes prepare the required caches. An unchanged cached owner switch still skips image synchronization.
